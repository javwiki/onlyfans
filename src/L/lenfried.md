# lenfried（れんふりーど）(lenfried_now)

## 📝 简介

lenfried（れんふりーど，昵称レン，@lenfried_now），日本 cosplayer 与同人写真作者。X 简介自述"アニメ見てたりゲームしてたりしてるただのコスプレイヤーです。可愛いおにゃのことメイドさんが主食"（只是个看看动画打打游戏的 cosplayer，可爱女孩子和女仆是主食）。以自拍（自撮り）性感 cosplay 写真闻名，尤其擅长东方 Project（博丽灵梦等）角色，长期以同人 CD-ROM 写真集、自拍写真集形式自行出版作品；Fantia 自述"作为爱好拍涩涩的 cosplay 和户外露出"。运营 Fantia 粉丝俱乐部"lenfried House"，并设有避难（备用）X 账号 @lenfried_new。
