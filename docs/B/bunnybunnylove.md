# 爱露露

## 📝 简介

爱露露（Bunny Bunny Love，亦见「兔崽」「愛露出」等写法）是马来西亚裔的成人内容创作者。2018 年前后她因在台北夜店、百货公司、更衣室、楼梯间等公共场所拍摄「野外露出」影片而受到关注，作品随后经 TikTok（抖音国际版）与 Tumblr 传播，被港台媒体与成人资讯站大量报道，一度被称为「抖音女神」。

报道普遍称其当时常驻台北、内容以户外暴露与自拍为主。她使用的 X 账号 `@bunnybunnylove` 现已停用，页面显示 Account suspended，因此无法核验简介、粉丝数等细节，也未找到其他可确认的官方账号。
