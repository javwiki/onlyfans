# UGC 成人内容：各国与地区法律概览

资料核对日期：2026-10-09。本文覆盖美国、英国、法国、德国、澳大利亚、中国大陆、日本、韩国、新加坡、印度和台湾，并补充欧盟平台规则；并非全球逐国穷尽清单。来源以法律原文、法院和监管机构文件为主。概览用于理解规则，不能代替针对具体内容、所在地及运营方式的法律意见。

## UGC 与法律判断

UGC porn 指用户自行上传或提供的成人性内容，包括订阅帖、视频、直播和私信中的内容。UGC 是内容来源的描述，不是法律豁免：需要分别判断制作、上传传播、平台托管和用户访问，付费墙也不自动免除相关义务。

阅读下表时，应区分一般成人性内容与各法域定义的“淫秽”“猥亵”等法律类别；各地定义不同，不能把所有裸露或成人题材都当作同一种犯罪。拍摄同意与公开发布授权同样应分开确认。

### 美国：非自愿私密影像下架

FTC 对 TAKE IT DOWN Act 第 3 节的执法自 **2026-05-19** 起实施：受覆盖的平台须提供有效的下架请求机制，并在收到有效请求后 **48 小时内**移除未经同意发布的私密影像及已知相同副本。该要求也涉及适用范围内的合成私密影像；它不是对所有内容投诉统一设置 48 小时处理期限。[FTC 合规说明](https://www.ftc.gov/business-guidance/resources/complying-take-it-down-act)

### 欧盟：成员国法律之外的平台义务

欧盟不是单一国家，DSA（《数字服务法》）也不是一张统一的成人内容经营许可。欧盟委员会于 **2025-05-27** 对 Pornhub、Stripchat、XNXX 与 XVideos 启动涉及未成年人保护的正式程序，关注年龄核验等措施。这说明成人平台须面对 DSA 的平台治理要求；本文引用的是启动调查的公告，不能据此认定最终违法结论。[欧盟委员会公告](https://digital-strategy.ec.europa.eu/en/news/commission-opens-investigations-safeguard-minors-pornographic-content-under-digital-services-act)

欧盟还提供保护隐私的年龄核验方案框架，帮助用户证明达到相关年龄门槛。该技术方案与成员国各自的内容、刑事及年龄限制规则需要分别理解。[欧盟年龄核验说明](https://digital-strategy.ec.europa.eu/en/policies/eu-age-verification)

## 怎样判断一个具体平台或上传行为

1. 确定拍摄者、上传者、平台运营者及目标用户所在法域，并区分制作、发布、经营与访问行为。
2. 确定内容的法律类别，核实出镜者身份、拍摄时年龄以及拍摄和传播授权；仅核验上传账号不足以证明所有出镜者符合要求。
3. 将创作者身份核验、出镜者记录义务和观众年龄核验分别审查；例如美国制作主体记录要求与英国观众访问控制处理的是不同问题。
4. 检查适用的下架机制、用户申诉及隐私保护要求，并分别阅读平台和支付方规则。
5. 对跨境适用、生效日期、法定例外及具体内容分类有疑问时，回到官方现行法与当地法律意见核对。

以上是根据所列制度整理的审查路径，不代表采取这些步骤即可获得经营许可或免除责任。
