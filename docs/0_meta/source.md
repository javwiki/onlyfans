## X 用户名

目录和旧页面里的 X 用户名大多不可信。很多是按显示名或拼音直接填的，实际账号经常是同名的其他人、空号，或已经停用。

只有显示名、简介或主页链接能对上同一个人时，才写入 `list.yaml` 的 `x` 字段和页面链接。对不上的不保留，也不改写成“可能是”。字母索引里的 `@handle` 必须和这个已核对的字段一致；没有 `x` 字段的条目按用户名列出，不加 `@`。
